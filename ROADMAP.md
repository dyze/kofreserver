## 0.3

1. Backup of all data folder and configuration files. Customizable thru a json file. By default, triggered every day at custom hour. Create an archive in fast compression mode. Apply best practice for backups: one each day, one each week, on per month. Limit total number of files.
2. Email notification system for Admin. Customizable thru json. Notify if user validation is pending or for important cases (unwanted restarts, backup problem). Send every day a summary.
